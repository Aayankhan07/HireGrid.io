# Sample Resumes Library — HireGrid.io

This directory contains sample candidate resume PDF files that recruiters and developers can use to quickly test candidate screening runs on **HireGrid.io**.

### 📄 Included Samples

1. `sample_candidate_resume.pdf`: Standard full-stack developer resume containing contact information, skills (Python, FastAPI, React, Docker), experience, and education details.

---

### 💡 Usage Instructions

1. Log into HireGrid.io (`http://localhost:3000`).
2. Click **"Create Screening Run"**.
3. Drag & drop the PDF files in this folder into the upload area.
4. Review real-time candidate analysis and score rankings!
